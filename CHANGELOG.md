# Changelog

## Final transport-aware revision

This repository was updated to match the revised computational manuscript.

### Added
- final transport-aware MATLAB analysis;
- separate nanoparticle-bound and free-drug compartments;
- blood, MPS, healthy-wall, plaque-cap, and plaque-core transport;
- dimensionally consistent pH/ROS release functions;
- held-out ROS-release benchmarking and leave-one-concentration-out analysis;
- Pareto-balanced multi-objective selection;
- paired quasi-Monte Carlo uncertainty analysis;
- Jansen/Saltelli global sensitivity analysis;
- candidate-screening, uncertainty-sample, and sensitivity-sample convergence checks;
- paired effect sizes and empirical uncertainty intervals;
- complete parameter provenance and reference audit;
- contextual external circulation benchmark;
- independent Python reproduction of the core screening, uncertainty, and convergence analyses.

### Removed or superseded
- release-only targeting-index interpretation;
- genetic-algorithm and pharmacoeconomic claims from the earlier project version;
- clinical-stage optimization claims;
- older manuscript PDFs and the unversioned intermediate MATLAB script.

### Interpretation
The repository now represents an in-silico exposure-screening framework. It does not establish nanoparticle safety, therapeutic efficacy, validated plaque targeting, or clinical feasibility.
